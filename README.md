# Focus – ToDo App Task

A minimalist task management dashboard built with **Laravel 13**, **PHP 8.4**, and **Tailwind CSS v4** (via Vite). The application focuses on clean code principles, structured database relationships, and a modern design system.

## ✨ Features Implemented

* **User & Task Architecture:** Complete database migrations with a structured One-to-Many relationship.
* **Task Management:** Robust `TaskController` handling secure CRUD operations.
* **Server-Side Validation:** Type-safe request validation utilizing PHP Enums for status and priority tracking.
* **Modern UI:** Local Tailwind v4 setup bundled via Vite, featuring custom design tokens and dynamic interactions.

---

## 🛠️ Tech Stack

* **Backend:** Laravel 13 / PHP 8.4
* **Frontend:** Blade Components / Tailwind CSS v4 (Local / Offline bundle)
* **Database:** PostgreSQL / MySQL
